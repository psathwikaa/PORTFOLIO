## 🚀 About Me

I am a **Full-Stack Developer** and **Agentic AI Engineer** passionate about building robust web applications, autonomous AI agents, and domain-specific quality evaluation frameworks. Currently pursuing my Master's Degree at **Blekinge Institute of Technology (BTH)** in Sweden.

- 🌐 **Full-Stack Web Dev:** Building production-grade Web Applications with **React 19**, **Next.js 15**, **TypeScript**, **Node.js**, **Python**, and **Tailwind CSS**.
- 🤖 **Agentic AI & ML:** Developing intelligent AI agents, RAG workflows, and multi-agent systems using **LangChain**, **LlamaIndex**, **CrewAI**, **LangGraph**, **Google ADK**, and **Gemini API**. Active participant in **Kaggle Agentic AI Competitions & Hackathons**.
- 🔬 **Master's Thesis:** Formulated a domain-specific software quality evaluation framework adapted from **ISO/IEC 25010:2023** for real-time gesture-based AAC assistive systems (in collaboration with **2Tango Signs / Neurodiversity Foundation**).
- 🛠️ **Open Source:** Active contributor to open-source projects including **DrivenData's `deon`** (LaTeX ethics checklist CLI) and **Home Assistant Core**.
